    关于数据来源

    来源数据 · 非官方站点

    台风清单、实况及预报取自海南气象“南海天气”台风路径页面所用的公开网页接口。本站为独立整理展示，不代表来源机构；该接口没有稳定开放 API 的服务承诺。

    GitHub Actions 计划每15分钟获取并保存数据，调度和部署可能延迟。超过45分钟未成功同步时提示过期；活跃台风实况时次超过12小时时额外提示核实。停止编号记录只作为历史资料。

    “刷新快照”仅读取本站已保存的数据，不直接请求来源。来源最近5条预警公报不构成完整地区有效预警清单，空列表不代表无预警；请到官方原站阅读完整公报、防御指南及解除信息。

    路径使用真实来源坐标，地理背景为简化示意，不用于导航或精确距离判断。重要天气决策请使用当地官方渠道。
